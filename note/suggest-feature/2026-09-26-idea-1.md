## 🟢 Quick win (< ครึ่งวัน)

- **สลับลำดับตัวเลือกในควิซด้วย**

  - สลับ options แล้ว map `answer` index ใหม่
  - ไฟล์: `lib/screens/quiz_play_screen.dart` (+ test ใน `test/widget_test.dart`) — **S**

- **ทบทวนข้อที่ตอบผิดหลังจบควิซ**
  - `_ResultView` แสดงแค่ % กับข้อความให้กำลังใจ ไม่บอกว่าผิดข้อไหน ทั้งที่ `QuizQuestion` มี `explanation` อยู่แล้ว
  - เก็บ list ข้อที่ผิดระหว่างเล่น → แสดงรายการ + ปุ่ม "ทำเฉพาะข้อที่ผิด" (ส่ง questions ที่ผิดกลับเข้า `QuizPlayScreen` ตัวเดิมได้เลย)
  - ไฟล์: `lib/screens/quiz_play_screen.dart` — **S**

- **ลิงก์คำศัพท์ในบทเรียน → Glossary**
  - มี glossary 20+ คำ ([lib/data/glossary.dart](../../lib/data/glossary.dart)) แต่เข้าได้ทางเดียวจากการ์ดหน้าแรก บทเรียนพูดถึงคำเหล่านี้ตลอด (setState, BuildContext, const…)
  - ใน `ParagraphBlock` ไฮไลต์คำที่ตรงกับ glossary แตะแล้วเปิด bottom sheet ความหมาย

## 🔥 Impact สูง

- **Streak / เป้าหมายรายวัน**
  - หน้าแรกมี `dailyTips` เปลี่ยนตามวัน (`DateTime.now().day`) อยู่แล้ว แต่ไม่มีอะไรดึงให้กลับมาเปิดแอปทุกวัน
  - เก็บ `lastActiveDate` + `streak` ใน `AppState` (นับเมื่อเรียนจบบท/ทำควิซ) แสดงที่ `_HomeHeader` และเพิ่ม badge "🔥 7 วันติด"
  - ไฟล์: `lib/state/app_state.dart`, `lib/screens/home_screen.dart`, `lib/screens/profile_screen.dart` — **M**

- **ปลดล็อก "เรียนจบ" ด้วยควิซท้ายบท แทนการกดเองเฉยๆ**
  - ตอนนี้ปุ่ม "ทำเครื่องหมายว่าเรียนจบ" ([lesson_screen.dart:68](../../lib/screens/lesson_screen.dart#L68)) กด toggle ได้ทันที → progress / badge ทั้งหมดในโปรไฟล์ไม่สะท้อนความเข้าใจจริง
  - ทุก `Lesson` มี `quiz` อยู่แล้ว: ให้กดจบ = เข้าควิซบทนั้น ผ่าน ≥ 70% ค่อย mark completed (ยังมีทางข้ามแบบ "ข้ามไปก่อน" ได้)
  - ไฟล์: `lib/screens/lesson_screen.dart`, `lib/screens/quiz_play_screen.dart` (callback ตอนผ่าน) — **M**

- **Playground / Challenge "เขียนให้ได้หน้าตาแบบนี้"**
  - เดโมทุกตัว (`lib/demos/`) เป็นแบบ "ปรับค่าแล้วดูโค้ด" อยู่แล้ว ต่อยอดเป็นโจทย์กลับด้าน: โชว์ภาพเป้าหมาย ให้ผู้เรียนปรับ slider/ตัวเลือกใน demo ให้ตรง แล้วเช็คผล
  - เริ่มจาก `row_column_demo.dart` / `container_demo.dart` ที่ state ชัดเจน (alignment, padding, color) — เทียบ state กับเฉลยได้ตรงๆ
  - ไฟล์: `lib/demos/*`, `lib/widgets/demo_kit.dart`, `lib/models/lesson.dart` (block ใหม่ `ChallengeBlock`) — **L**
